# 冒险岛怀旧服自动挂机工具

一个基于 Python 的冒险岛怀旧服自动挂机辅助工具，支持窗口识别、图像匹配、自动攻击、自动恢复和技能循环。

## 功能列表

| 序号 | 功能 | 说明 |
|------|------|------|
| 1 | 获取游戏窗口句柄 | 自动枚举系统窗口，搜索并选择游戏窗口 |
| 2 | 上传图片识别角色 | 上传角色截图，通过模板匹配定位角色位置 |
| 3 | 上传图片识别怪物 | 上传怪物截图（支持多个），实时匹配画面中的怪物 |
| 4 | 定点移动范围 | 设置移动中心点和半径，角色在范围内巡逻 |
| 5 | 攻击范围设置 | 设置攻击范围（像素），怪物进入范围自动攻击 |
| 6 | 自动加血加蓝 | 设置HP/MP恢复按键和阈值，低于阈值自动使用药水 |
| 7 | 技能按键与冷却 | 设置多个技能按键和冷却时间，自动循环释放 |

## 使用教程

### 第一步：选择游戏窗口

1. 打开冒险岛游戏客户端
2. 在工具的「窗口选择」标签页中，输入标题关键字（如"冒险岛"）
3. 点击「搜索」按钮
4. 在列表中选中游戏窗口，点击「选择此窗口」

### 第二步：上传图片模板

1. 在游戏中截取角色和怪物的清晰截图
2. 在「图片模板」标签页上传角色截图
3. 点击「添加怪物图片」上传一个或多个怪物截图
4. 调整匹配阈值（默认0.75，越低越容易匹配但误判率越高）

> **截图建议**: 截取角色/怪物的独特外观区域，尺寸建议 50x50 ~ 100x100 像素，避免截取过大的区域。

### 第三步：设置移动和攻击

1. 在「移动与攻击」标签页设置：
   - 移动中心点坐标和半径（角色巡逻范围）
   - 攻击按键（如 `x`）和攻击范围（像素）
   - 扫描间隔和匹配阈值

### 第四步：设置自动恢复

1. 在「自动恢复」标签页设置：
   - HP/MP 恢复按键
   - HP/MP 阈值（百分比，低于此值自动使用药水）
   - HP/MP 血条区域坐标（相对于游戏窗口客户区）

> **血条区域**: 需要填写游戏画面中 HP/MP 血条的位置和大小。工具通过分析该区域中红色/蓝色像素的比例来估算百分比。

### 第五步：设置技能

1. 在「技能设置」标签页点击「添加技能」
2. 填写技能名称、按键和冷却时间
3. 可添加多个技能，引擎会按冷却时间自动循环释放

### 第六步：开始挂机

1. 确认所有设置无误
2. 点击「开始挂机」按钮
3. 在「运行状态」标签页查看实时日志和统计数据
4. 可随时暂停或停止

## 常见问题

### Q: 找不到游戏窗口？
A: 确保游戏已经打开，尝试点击「刷新所有窗口」查看所有可见窗口。

### Q: 图像匹配不到角色/怪物？
A: 尝试降低匹配阈值（如0.6），或重新截取更清晰的模板图片。

### Q: HP/MP 百分比显示不准确？
A: 检查血条区域坐标是否正确。可以先用截图工具测量游戏中血条的位置和大小。

### Q: 按键没有反应？
A: 确保游戏窗口在前台，部分游戏可能需要以管理员权限运行本工具。

### Q: 程序报错缺少模块？
A: 运行 `pip install -r requirements.txt` 安装所有依赖。

## 技术说明

- **窗口截图**: 使用 Win32 API 的 `PrintWindow` / `BitBlt` 捕获游戏窗口画面
- **图像识别**: 使用 OpenCV 模板匹配（`cv2.matchTemplate`），支持多尺度匹配和非极大值抑制
- **血条分析**: 使用 HSV 颜色空间分析血条区域的像素颜色比例
- **输入模拟**: 使用 `keybd_event` 和 `PostMessage` 模拟键盘输入
- **GUI框架**: PyQt5，多线程运行保证界面流畅
